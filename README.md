# 🟢 QueueX - 스마트 웨이팅 시스템

> “줄이 아닌, 가장 적합한 고객을 호출하는 시스템”

---

## 📌 프로젝트 소개

QueueX는 기존 웨이팅 시스템의 단순 순번(FIFO) 방식에서 발생하는 비효율을 개선하기 위해 개발된  
**인원수 기반 고객 추천 웨이팅 시스템**입니다.

기존 시스템은 고객의 인원수를 고려하지 않아  
좌석이 비어 있음에도 입장이 불가능한 문제가 발생합니다.

QueueX는 이를 해결하기 위해  
👉 **매장 수용 인원에 맞는 고객을 자동으로 추천하는 방식**을 도입했습니다.

---

## 🎯 주요 기능

### 👤 고객 기능
- 전화번호 / 비밀번호 기반 로그인 및 회원가입
- 가게 선택
- 메뉴 조회
- 대기 등록
- 선주문 기능
- 내 대기 상태 조회
- 대기 취소

---

### 🛠 관리자 기능
- 관리자 ID / 비밀번호 기반 로그인
- 비밀번호 해시 비교
- 로그인 3회 실패 제한
- 매장 선택 및 운영
- 인원수 기반 고객 추천 ⭐
- 고객 호출
- 입장 처리 / 노쇼 처리
- 통계 조회

## 사용자 유형 선택

시작 화면에서 아래와 같이 사용자 유형을 먼저 선택합니다.

```text
[사용자 유형 선택]

2. 관리자
3. 종료
```

## 고객 플로우

고객을 선택하면 전화번호와 비밀번호를 통해 로그인 또는 회원가입을 진행합니다.

```text
전화번호 입력 >>
비밀번호 입력 >>
```

로그인 성공 후 고객 메뉴는 아래 흐름으로 진행됩니다.

```text
[고객 메뉴]
1. 가게 선택
2. 내 대기 조회
3. 종료
```

### 1. 가게 선택
- 가게 목록을 보여주고 원하는 가게를 선택합니다.
- 가게 선택 후 해당 가게 메뉴를 조회할 수 있습니다.

### 2. 대기 등록
- 가게 선택 후 대기 등록을 선택합니다.
- 인원수를 입력합니다.
- 인원수 입력 후 선주문을 진행합니다.
- `주문 완료`를 선택할 때까지 메뉴와 수량 입력을 반복합니다.
- 대기 등록 완료 후 가게명, 대기번호, 인원수, 주문내역을 출력합니다.

### 3. 내 대기 조회
- 현재 대기 중인 가게, 대기번호, 내 순서, 인원수, 주문내역을 조회합니다.
- 필요 시 대기 취소를 선택할 수 있습니다.
- 취소 확인 후 상태를 `CANCELED`로 변경합니다.

## 관리자 플로우

관리자를 선택하면 관리자 인증 절차를 진행합니다.

```text
관리자 ID 입력 >>
비밀번호 입력 >>
```

- 입력한 비밀번호는 해시 비교를 통해 검증합니다.
- 로그인은 최대 3회까지만 시도할 수 있습니다.
- 인증 성공 후 관리자 메뉴로 이동합니다.

```text
[관리자 메뉴]
1. 가게 선택 및 운영 시작
2. 통계 조회
3. 로그아웃
```

### 1. 가게 선택 및 운영 시작
- 관리자 본인에게 속한 가게 목록만 출력합니다.
- 가게를 선택한 뒤 현재 대기 목록을 조회합니다.
- 수용 가능한 인원을 입력합니다.
- 입력한 인원수 기준으로 추천 순위를 계산합니다.
- 다음 손님을 호출하거나 취소할 수 있습니다.

### 2. 호출 이후 처리
- 호출 완료 후 현재 호출 고객을 보여줍니다.
- 이후 아래 동작을 선택할 수 있습니다.
  - 입장 처리
  - 노쇼 처리
  - 관리자 화면으로 돌아가기
- 입장 또는 노쇼 처리 후에는 다음 추천 순위를 다시 보여주며, 관리자가 돌아가기 전까지 운영 흐름을 반복합니다.

### 3. 통계 조회
- 가게를 선택한 뒤 오늘 통계를 조회합니다.
- 통계 항목은 총 방문 고객 수, 총 웨이팅 수, 메뉴별 주문 건수, 노쇼 건수를 포함합니다.

### 📌 인원수 기반 고객 추천

## 프로젝트 구조

- `src/main/java/` : Java 소스 코드
- `src/main/java/app/Main.java` : 애플리케이션 엔트리포인트
- `docker/mysql/init/` : Docker MySQL 초기화 SQL
- `pom.xml` : Maven 빌드 설정
- `Dockerfile` : 앱 Docker 빌드 설정
- `docker-compose.yml` : 앱 + MySQL Docker Compose 설정

## 빌드 및 실행

로컬 Maven 빌드:

```bash
mvn clean package
```

JAR 실행:

```bash
java -jar target/queuex-1.0-SNAPSHOT-jar-with-dependencies.jar
```

## Docker 실행

앱과 DB를 한 번에 실행:

```bash
docker compose up --build -d
```

초기 스키마와 테스트 데이터는 `docker/mysql/init/` 아래 SQL 파일이 자동 실행됩니다.

앱 로그 확인:

```bash
docker compose logs -f app
```

DB 로그 확인:

```bash
docker compose logs -f mysql
```

현재 `app` 컨테이너는 [`Main.java`](/Users/miju/QueueX/src/main/java/app/Main.java) 실행 후 종료될 수 있습니다. 장시간 실행되는 서버 기능을 붙이면 계속 살아 있게 됩니다.
